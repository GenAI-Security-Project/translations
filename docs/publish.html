For now this page runs only Process 4 — Assemble for Layout: a plain, watermarked ("DRAFT – NOT FOR DISTRIBUTION") .docx of a fully reviewed translation, plus its figure files, for a designer to lay out in the template by hand. Final PDF publishing (Process 2) is not offered here while it's being set up.

How to run a layout handoff

  1. Find a row below marked ready and press Copy asset id.
  2. Press Run layout handoff. GitHub's own Actions page opens — you use your normal GitHub sign-in there, no token needed.
  3. Click Run workflow, leave the branch as main, paste the asset id, type the locale shown in the row, and click the green Run workflow button.
  4. When the run finishes (a few minutes), open it and download layout-handoff-<asset>-<locale> from Artifacts (kept 14 days), then send it to the designer.

Only translations managers can run it (the translations-managers team, or Maintain/Admin on the repo); anyone else's run stops at the first step. A locale is only ready once every section is reviewed — the workflow refuses anything else.
