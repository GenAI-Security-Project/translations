Adding a language: translations managers can press + Add languages under a document, tick the languages, and press Request translation. GitHub opens the request already filled in; pressing Create there registers the languages and starts a machine-drafted translation of each, which arrives as a pull request for review.

Every onboarded document and its translations. Review progress comes from each language's status.json; live activity comes straight from GitHub: Queued and Drafting… while a machine draft is being made, Draft ready for review (with its pull request) once it's done, and Drafting failed with a link to the log if a run didn't finish. A language links to its translated files once reviewed sections are on main.
