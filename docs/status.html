Adding a language: translations managers can press + Add languages under a document, tick the languages, and press Request translation. GitHub opens the request already filled in; pressing Create there registers the languages and starts a machine-drafted translation of each, which arrives as a pull request for review.

Every onboarded document and its translations, read live from each locale's status.json. A locale links to its actual translated files on GitHub once at least one section has been drafted; one registered with no draft yet shows "no sections yet" and isn't linked, since there's nothing on main to link to.
