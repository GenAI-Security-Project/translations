Upload a finished English asset to start translating it, or add locales to one that's already onboarded. This one form does both — see tooling/README.md for how the pipeline works underneath.

1. GitHub access

Paste a fine-grained personal access token scoped to GenAI-Security-Project/translations and GenAI-Security-Project/translations-templates, with Contents: Read and write permission (needed to check render-template coverage and stage your upload). Generate one at github.com/settings/personal-access-tokens/new. The token is kept only in this browser tab's memory — it's never sent anywhere but api.github.com, and it's gone when you close the tab.
