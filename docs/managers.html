    How managers are added or removed

    • A manager is anyone with the Maintain or Admin role on the translations repository. Every pipeline workflow checks this when it runs.
    • A repository or organization admin adds people in GitHub: org members through the translations-managers team, and people outside the organization as collaborators with Maintain on this repository only.
    • Nothing on this site changes who is a manager. This list is refreshed from GitHub once a day (and whenever the sync-managers workflow is run).
    • Organization owners have Admin on every repository. Owners who don't manage translations are left off this list (tooling/managers_exclude.txt).
