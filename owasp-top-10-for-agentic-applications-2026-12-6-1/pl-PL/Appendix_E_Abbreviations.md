# Załącznik E – Skróty

A2A — Agent-to-Agent (protokół/katalog/komunikacja)
AARS — Agentic AI Risk Scoring (pole AIVSS)
AI — sztuczna inteligencja
AIBOM — AI Bill of Materials
API — interfejs programowania aplikacji
AS — Agentic System (system agentowy)
ASI — Agentic Security Initiative / Agentic Security Item
AWS — Amazon Web Services
BOM — wykaz materiałów (Bill of Materials)
CDR — oczyszczanie i rekonstrukcja treści (Content Disarm and Reconstruction)
CI/CD — ciągła integracja / ciągłe wdrażanie (Continuous Integration / Continuous Deployment)
CLI — interfejs wiersza poleceń (Command Line Interface)
CRUD — Create, Read, Update, Delete (tworzenie, odczyt, aktualizacja, usuwanie)
CV — naruszenia zgodności (Compliance Violations, kategoria punktacji AIVSS)
DB — baza danych
DDoS — rozproszona odmowa usługi (Distributed Denial of Service)
DNS — system nazw domen (Domain Name System)
EDR — wykrywanie i reagowanie na zagrożenia punktów końcowych (Endpoint Detection & Response)
gRPC — Google Remote Procedure Call (protokół)
HITL — nadzór człowieka (Human in the Loop)
HSM — sprzętowy moduł bezpieczeństwa (Hardware Security Module)
IAM — zarządzanie tożsamością i dostępem (Identity & Access Management)
ID — identyfikator
IR — reagowanie na incydenty (Incident Response)
JIT — Just-In-Time (poświadczenia lub uprawnienia)
KMS — usługa zarządzania kluczami (Key Management Service)
LLM — duży model językowy (Large Language Model)
MCP — Model Context Protocol
MITM — atak man-in-the-middle
MFA — uwierzytelnianie wieloskładnikowe (Multi-Factor Authentication)
MLOps — operacje uczenia maszynowego (Machine Learning Operations)
mTLS — wzajemne TLS (Mutual Transport Layer Security)
NFA — atrybuty niefunkcjonalne (Non-Functional Attributes; w kontekście AIVSS/mapowania, obecne niejawnie poprzez pola AIVSS)
NHI — tożsamość nie-ludzka (Non-Human Identity)
NVD — National Vulnerability Database
OAuth — Open Authorization
OSINT — biały wywiad (Open-Source Intelligence)
OS — bezpieczeństwo operacyjne (Operational Security, kategoria punktacji AIVSS)
PEP / PDP — punkt egzekwowania polityk / punkt decyzyjny polityk (Policy Enforcement Point / Policy Decision Point)
PKI — infrastruktura klucza publicznego (Public Key Infrastructure)
RAG — generowanie wspomagane wyszukiwaniem (Retrieval-Augmented Generation)
RCE — zdalne wykonanie kodu (Remote Code Execution)
SBOM — wykaz materiałów oprogramowania (Software Bill of Materials)
SDK — zestaw narzędzi dla deweloperów (Software Development Kit; pojawia się w odnośnikach)
SSH — Secure Shell
SSRF — fałszowanie żądań po stronie serwera (Server-Side Request Forgery)
TTL — czas życia (Time to Live)
UI — interfejs użytkownika
VS Code — Visual Studio Code (pojawia się w przykładach)
WASM — WebAssembly (wymieniony w kontekście RCE)
