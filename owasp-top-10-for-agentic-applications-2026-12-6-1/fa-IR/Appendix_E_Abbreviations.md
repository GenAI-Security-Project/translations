# پیوست E – اختصارات

A2A - عامل‌به‌عامل (پروتکل/دایرکتوری/ارتباط)

AARS - امتیازدهی ریسک هوش مصنوعی عامل‌محور (فیلد AIVSS)

AIBOM - فهرست مواد هوش مصنوعی

AI - هوش مصنوعی

API - رابط برنامه‌نویسی کاربردی

AS - سامانه عامل‌محور

ASI - ابتکار امنیت عامل‌محور / مورد امنیت عامل‌محور

AWS - Amazon Web Services

BOM - فهرست مواد

CDR - خلع‌سلاح و بازسازی محتوا

CI/CD - یکپارچه‌سازی مستمر / استقرار مستمر

CLI - رابط خط فرمان

CRUD - ایجاد، خواندن، به‌روزرسانی، حذف

CV - نقض‌های انطباق (دسته‌بندی امتیازدهی AIVSS)

DB - پایگاه‌داده

DDOS / DDoS - انکار سرویس توزیع‌شده

DNS - سامانه نام دامنه

EDR - تشخیص و پاسخ نقطه‌پایانی

gRPC - Google Remote Procedure Call (پروتکل)

HITL - انسان در حلقه

HSM - ماژول امنیت سخت‌افزاری

IAM - مدیریت هویت و دسترسی

ID - شناسه

IR - پاسخ به رخداد

JIT - درست‌به‌موقع (اعتبارنامه یا امتیاز)

KMS - سرویس مدیریت کلید

LLM - مدل زبانی بزرگ

MCP - پروتکل زمینه مدل

MITM - مرد میانی

MFA - احرازهویت چندعاملی

MLOps - عملیات یادگیری ماشین

mTLS - امنیت لایه انتقال متقابل

NFA - ویژگی‌های غیرکارکردی (در زمینه نگاشت AIVSS)

NHI - هویت غیرانسانی

NVD - پایگاه‌داده ملی آسیب‌پذیری

OAuth - مجوزدهی باز

OSINT - هوش منبع‌باز

OS - امنیت عملیاتی (دسته‌بندی امتیازدهی AIVSS)

PEP / PDP - نقطه اجرای سیاست / نقطه تصمیم‌گیری سیاست

PKI - زیرساخت کلید عمومی

RAG - تولید تقویت‌شده با بازیابی

RCE - اجرای کد از راه دور

SBOM - فهرست مواد نرم‌افزاری

SDK - جعبه‌ابزار توسعه نرم‌افزار

SSH - پوسته امن

SSRF - جعل درخواست سمت سرور

TTL - زمان زندگی

UI - رابط کاربری

VS Code - Visual Studio Code

WASM - وب‌اسمبلی
