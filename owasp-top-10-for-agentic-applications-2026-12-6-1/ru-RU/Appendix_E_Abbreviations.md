# Приложение E — Сокращения

A2A — Agent-to-Agent (протокол/каталог/коммуникация) DNS — система доменных имён (Domain Name System) EDR — обнаружение и реагирование на угрозы на конечных точках (Endpoint Detection & Response) AARS — Agentic AI Risk Scoring (поле AIVSS) gRPC — Google Remote Procedure Call (протокол) AIBOM — AI Bill of Materials HITL — участие человека в цикле (Human in the Loop) AI — искусственный интеллект HSM — аппаратный модуль безопасности (Hardware Security Module) API — интерфейс программирования приложений IAM — управление идентификацией и доступом (Identity & Access Management) AS — Agentic System (агентная система) ID — идентификатор ASI — Agentic Security Initiative / Agentic Security Item IR — реагирование на инциденты (Incident Response)

JIT — Just-In-Time (учётные данные или привилегии «точно в срок») AWS — Amazon Web Services

KMS — служба управления ключами (Key Management Service) BOM — спецификация материалов (Bill of Materials)

LLM — большая языковая модель (Large Language Model) CDR — очистка и восстановление содержимого (Content Disarm and Reconstruction)

MCP — Model Context Protocol CI/CD — непрерывная интеграция / непрерывное развёртывание (Continuous Integration / Continuous Deployment) MITM — «человек посередине» (Man-in-the-Middle) CLI — интерфейс командной строки (Command Line Interface) MFA — многофакторная аутентификация (Multi-Factor Authentication) CRUD — создание, чтение, обновление, удаление (Create, Read, Update, Delete) MLOps — эксплуатация систем машинного обучения (Machine Learning Operations) CV — нарушения соответствия требованиям (Compliance Violations, категория оценки AIVSS) mTLS — взаимный TLS (Mutual Transport Layer Security)

NFA — нефункциональные атрибуты (в контексте AIVSS/сопоставления; неявно фигурирует через поля AIVSS) DB — база данных (Database) DDOS / DDoS — распределённая атака типа «отказ в обслуживании» (Distributed Denial of Service)

NHI — нечеловеческая идентичность (Non-Human Identity) SBOM — спецификация программных материалов (Software Bill of Materials)

NVD — Национальная база данных уязвимостей (National Vulnerability Database) SDK — набор средств разработки (Software Development Kit, встречается в ссылках) OAuth — Open Authorization SSH — Secure Shell OSINT — разведка на основе открытых источников (Open-Source Intelligence) SSRF — подделка запроса на стороне сервера (Server-Side Request Forgery) OS — операционная безопасность (Operational Security, категория оценки AIVSS) TTL — время жизни (Time to Live)

PEP / PDP — точка принудительного применения политики / точка принятия решения по политике (Policy Enforcement Point / Policy Decision Point) UI — пользовательский интерфейс (User Interface) PKI — инфраструктура открытых ключей (Public Key Infrastructure) VS Code — Visual Studio Code (упоминается в примерах)

RAG — генерация с дополненным поиском (Retrieval-Augmented Generation) WASM — WebAssembly (упоминается в разделе о RCE)

RCE — удалённое выполнение кода (Remote Code Execution)
