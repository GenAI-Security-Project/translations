# Приложение E — Сокращения

A2A — Agent-to-Agent (протокол/каталог/коммуникация)
AARS — Agentic AI Risk Scoring (поле AIVSS)
AI — искусственный интеллект
AIBOM — AI Bill of Materials
API — интерфейс программирования приложений
AS — Agentic System (агентная система)
ASI — Agentic Security Initiative / Agentic Security Item
AWS — Amazon Web Services
BOM — спецификация материалов (Bill of Materials)
CDR — очистка и восстановление содержимого (Content Disarm and Reconstruction)
CI/CD — непрерывная интеграция / непрерывное развёртывание (Continuous Integration / Continuous Deployment)
CLI — интерфейс командной строки (Command Line Interface)
CRUD — создание, чтение, обновление, удаление (Create, Read, Update, Delete)
CV — нарушения соответствия требованиям (Compliance Violations, категория оценки AIVSS)
DB — база данных (Database)
DDOS / DDoS — распределённая атака типа отказ в обслуживании (Distributed Denial of Service)
DNS — система доменных имён (Domain Name System)
EDR — обнаружение и реагирование на угрозы на конечных точках (Endpoint Detection & Response)
gRPC — Google Remote Procedure Call (протокол)
HITL — Человек в контуре управления (Human in the Loop)
HSM — аппаратный модуль безопасности (Hardware Security Module)
IAM — управление идентификацией и доступом (Identity & Access Management)
ID — идентификатор
IR — реагирование на инциденты (Incident Response)
JIT — Just-In-Time (учётные данные или привилегии по запросу)
KMS — служба управления ключами (Key Management Service)
LLM — большая языковая модель (Large Language Model)
MCP — Протокол контекста модели (Model Context Protocol)
MFA — многофакторная аутентификация (Multi-Factor Authentication)
MITM — Человек посередине (Man-in-the-Middle)
MLOps — эксплуатация систем машинного обучения (Machine Learning Operations)
mTLS — взаимный TLS (Mutual Transport Layer Security)
NFA — нефункциональные атрибуты (в контексте AIVSS/сопоставления; неявно фигурирует через поля AIVSS)
NHI — нечеловеческая идентичность (Non-Human Identity)
NVD — Национальная база данных уязвимостей (National Vulnerability Database)
OAuth — Open Authorization
OS — операционная безопасность (Operational Security, категория оценки AIVSS)
OSINT — разведка на основе открытых источников (Open-Source Intelligence)
PEP / PDP — точка принудительного применения политики / точка принятия решения по политике (Policy Enforcement Point / Policy Decision Point)
PKI — инфраструктура открытых ключей (Public Key Infrastructure)
RAG — генерация с дополненным поиском (Retrieval-Augmented Generation)
RCE — удалённое выполнение кода (Remote Code Execution)
SBOM — спецификация программных материалов (Software Bill of Materials)
SDK — набор средств разработки (Software Development Kit, встречается в ссылках)
SSH — Secure Shell
SSRF — подделка запроса на стороне сервера (Server-Side Request Forgery)
TTL — время жизни (Time to Live)
UI — пользовательский интерфейс (User Interface)
VS Code — Visual Studio Code (упоминается в примерах)
WASM — WebAssembly (упоминается в разделе о RCE)
